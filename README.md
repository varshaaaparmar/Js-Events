# Dynamic Product Card Generator

A beginner-friendly JavaScript project that dynamically creates product cards using form inputs and DOM manipulation.

🔗 Live Demo

Live Demo

https://varshaaaparmar.github.io/Js-Events/card.html

## Features

* Add product name, image URL, price, and description
* Dynamically generate product cards
* Add Buy Now and Add to Cart buttons
* Change button text to "Added to Cart"
* Reset the form after submitting
* Product image hover effect
* Responsive and styled card layout

## Technologies Used

* HTML
* CSS
* JavaScript
* DOM Manipulation
* Event Listeners

## What I Practiced

* `querySelector()` and `querySelectorAll()`
* `createElement()`
* `classList.add()`
* `appendChild()`
* `addEventListener()`
* Form submission and `preventDefault()`
* Dynamically updating text and attributes
* Creating interactive UI elements with JavaScript
